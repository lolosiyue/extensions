# E鸣惊人：曹操傳

曹操傳的資料、技能及規則均內嵌於外部倉庫的 `extensions/emjr.lua`，主倉庫不新增來源檔或修改設定。曹操傳沿用 E鸣惊人（`emjr`）擴展包及現有建立房間、選將、技能詢問與戰鬥日誌介面。啟用此包後，在模式清單的「曹操传」分組選擇關卡；房主控制本關主將，其他位置可由 AI 補齊。

## 遊玩流程

1. 新進度從「01 颖川之战」開始。通關後回到建立房間介面，選擇下一關。每關保留原表的 2v3、3v3 或 3v5 人數與固定武將；副將位置由房主選擇，敵方副將從本劇情兵種池抽取。
2. 第1關擊敗張角即勝利，其餘普通關全殲敵人。曹操陣亡即失敗，第17關改為夏侯惇、第21關改為張遼；第7關另須保護獻帝。開局日誌顯示本關條件。
3. 通關第8關時，若典韋在該局陣亡，後續副將池移除典韋；第16關的郭嘉同理。普通關失敗不推進進度，也不保存該次退場。
4. 全部30關通關後開放自由選關。完整模式清單一直可見，但未通關前只允許目前進度的下一關；選到未開放關卡時，日誌提示應選關卡並結束該次開局。
5. 普通關勝利後可能發現神獸，日誌會提示。開始下一普通關前，在相同分組選「神兽挑战」；直接進入普通關代表跳過這次遭遇。挑戰勝利取得對應寶物，失敗結束本次遭遇；不影響普通關進度。
6. 每局開始可選擇一件已取得寶物或不裝備。靈氣從0開始，持有者擊殺其他角色時加1，上限3；寶物發動消耗1，神獸不受靈氣限制。

## 補充規則

使用者提供的30關、12位兵種／武將、四神獸與寶物文字為實作依據。以下原文未指定項目採用明確預設：

| 項目 | 實作 |
|---|---|
| 神獸遭遇率 | 普通關勝利後20%；未取得寶物的神獸優先；第30關不產生後續遭遇 |
| 神獸挑戰陣容 | 曹操與一位可選副將對一隻神獸，2v1 |
| 神獸體力 | 四神獸均6點 |
| 友方副將池 | 本地已載入的魏將及步兵、弓兵；排除同局固定武將、已選副將及已退場者 |
| 敵方副將池 | 步兵、弓兵、黃巾賊、猛虎兵、騎兵、槍兵、藤甲兵、鐵騎兵 |
| 寶物與靈氣 | 寶物永久解鎖；每局只選一件，靈氣不跨局保存 |
| 自由選關與退場 | 30關後保留原通關的退場紀錄；重玩原關時固定出戰者仍依關卡表配置 |

黃金鎧依補充原文：受到屬性傷害時防止此傷害。仁王、鏡鎧、藤甲透過既有虛擬裝備（ViewAsEquipSkill）機制提供防具效果。

| 狀態 | 效果與解除時機 |
|---|---|
| 中毒 | 下個判定階段結束時判定，梅花則受到1點無來源傷害，然後解除 |
| 禁咒 | 自己回合內不能使用或重鑄錦囊，至下個回合結束解除 |
| 麻痺 | 自己回合內不能使用殺，至下個回合結束解除 |
| 連環／翻面 | 立即進入相應原生狀態，依原生規則解除 |

## 存檔與來源

進度以房主暱稱的 UTF-8 十六進位識別，保存在伺服器設定的 `EmjrCaocao/v1/` 命名空間。不同暱稱各自保存；同暱稱共用該伺服器進度，應一次只開一個戰役房間。資料包含通關數、典韋／郭嘉退場、已取得寶物及待挑戰神獸，不保存牌局中途狀態。無法識別的存檔保留原值並停止開局；若結算時讀到另一房間已完成的更新，本局不覆蓋它。QSettings 讀取與寫入不構成原子交易，因此不支援同一進度的並行推進。

| 檔案 | 責任 |
|---|---|
| `extensions/emjr.lua` | 原包、30關資料、選將與勝敗、進度、武將、神獸、寶物及狀態技能 |
| `extensions/emjr-caocao.md` | 本說明 |
| `lua/ai/emjr-ai.lua` | 傳統 SmartAI 決策 |
| `lua/ai/isolated/emjr-ai.lua` | 隔離 SmartAI 決策 |

擴展與 AI 的最終權威仍為外部 `lolosiyue/extensions` 工作樹；只回寫本次檔案，不提交或推送。
